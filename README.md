# EIMP topic split files

這份檔案把 water / waste / noise 三個主題拆成：

- `topic-common.js`：三個主題共用互動，包含側選單、地圖、底圖切換、圖層開關、列表點選、快速定位、測站卡片更新。
- `ui-common.js`：所有主題共用的畫面欄位更新工具；重複顯示欄位使用簡短的 `data-field`，唯一控制元件才使用 `id`。
- `topic-common.css`：三個主題共用但不放回 `common-branch.css` 的補充樣式。
- `water.css` / `waste.css` / `noise.css`：各主題專用樣式。
- `water.js` / `waste.js` / `noise.js`：各主題資料與欄位設定。
- `water.html` / `waste.html` / `noise.html`：已改成引用上述拆分檔案。

後續建議：
1. 共用版面或共用互動改 `topic-common.css`、`topic-common.js`。
2. 單一主題的顏色、卡片、測站、案件資料改該主題自己的 css/js。
3. 後端 API 接上後，可以只改各主題 js 裡面的 `caseLists` 與 `layers` 資料來源。
4. 同一資料若會顯示在多種版型，請使用相同 `data-field`，不要新增重複 `id`。

## 本版火災調度調整（2026-07-13）

- 火災案件的「臨時轄區調度」新增兩種指派方式：
  - 車機指派（案件最近車組）：依案件座標計算直線距離，預設最近車機，並列出最近 3 部車機。
  - 轄區分隊（優先處理案件）：依行政區預設所屬分隊車機，並同時列出指定單位車機作為備選。
- 中和區示範案件預設轄區為二分隊；車機指派時，最近車機為 A11-0001（一分隊）。
- 指派摘要會顯示：
  - `臨時任務指派(火災)：車機指派A11-0001(一分隊)`
  - 選擇板橋區時：`臨時任務指派(火災)：分隊指派(一分隊)`
- 車機被派出後，畫面會依「所屬轄區（改派）／指定單位」規則顯示原負責行政區及接手分隊。
- 目前「確認指派」為前端示意，會顯示確認內容，尚未寫入後端資料庫或發送 LINE 通知。
